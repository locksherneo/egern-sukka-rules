## no_resolve

Sukka 源规则中的：

```text
IP-CIDR,...,no-resolve
IP-CIDR6,...,no-resolve
IP-ASN,...,no-resolve
GEOIP,...,no-resolve
```

会自动转换为 Egern Rule Set 顶层：

```yaml
no_resolve: true
```

只有源规则实际包含 `no-resolve` 时才会添加。

## Features

- 每 24 小时自动同步
- 直接读取 Sukka List
- 自动转换为 Egern YAML
- 精确保留 no-resolve 语义
- 所有规则值安全双引号
- 支持 DOMAIN-WILDCARD
- 支持 IP-ASN
- 支持 IPv6、百分号、正则
- 自动跳过 Deprecated 文件
- 自动跳过纯注释规则
- YAML 自动解析验证
- SHA256 版本校验
- 无变化不 Commit
- 转换失败不覆盖旧规则
- 自动生成转换报告

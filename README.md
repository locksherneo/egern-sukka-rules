```yaml
  - rule_set:
      match: "https://raw.githubusercontent.com/locksherneo/egern-sukka-rules/main/non_ip/ai.yaml"
      policy: 🤖 AI
      update_interval: 86400

  - rule_set:
      match: "https://raw.githubusercontent.com/locksherneo/egern-sukka-rules/main/ip/ai.yaml"
      policy: 🤖 AI
      update_interval: 86400

  - default:
      policy: DIRECT
```

## Features

- 每 24 小时自动同步
- 直接读取 Sukka List
- 自动转换 Egern YAML
- 所有规则值安全双引号
- 支持 DOMAIN-WILDCARD
- 支持 IP-ASN
- 支持正则和百分号字符
- 自动跳过 Deprecated 文件
- 自动跳过纯注释文件
- 自动 YAML 语法验证
- SHA256 版本校验
- 无变化不 Commit
- 转换失败不覆盖旧规则
- 自动生成转换报告
